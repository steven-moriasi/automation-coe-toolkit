# ADR 0002: Keep Governance Gates Outside the Priority Score

## Status

Accepted.

## Context

A single aggregate score can allow high economic value to mathematically cancel security,
continuity, or evidence deficiencies.

## Decision

Evaluate evidence and elevated-risk conditions before the candidate recommendation. Report
governance gates independently from value and feasibility.

## Consequences

- Attractive proposals cannot numerically bypass mandatory review.
- Reviewers see conditional approval work directly.
- Portfolio decisions require judgment across score, gates, strategy, and capacity.
